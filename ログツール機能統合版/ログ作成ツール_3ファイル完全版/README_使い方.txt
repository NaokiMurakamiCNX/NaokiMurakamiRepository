ログ作成ツール 3ファイル完全版 - 使い方

【同梱ファイル】
1. ログ作成ツール ver1.4.5_3ファイル完全版.html
   - 上部に「画面キャプチャツール」「定型文登録ツール」ボタンを追加済みです。

2. 画面キャプチャツール.html
   - 元の画像編集機能を保持した画面キャプチャツールです。
   - ログ作成ツールの「画面キャプチャツール」ボタンから別タブで開きます。

3. 定型文登録ツール.html
   - 元の定型文登録ツールです。
   - ログ作成ツールの「定型文登録ツール」ボタンから別タブで開きます。

【利用手順】
1. ZIPファイルを任意の場所に展開します。
2. 3つのHTMLファイルは同じフォルダに置いたままにしてください。
3. 「ログ作成ツール ver1.4.5_3ファイル完全版.html」をブラウザで開きます。
4. 上部の各ボタンから、画面キャプチャツール・定型文登録ツールを起動できます。

【注意事項】
- 「画面キャプチャツール.html」「定型文登録ツール.html」のファイル名を変更すると、ログ作成ツールから開けなくなります。
- ブラウザ設定によりポップアップがブロックされる場合は、このHTMLファイルのポップアップ許可を行ってください。
- 画面キャプチャ機能は、ブラウザや社内端末のセキュリティ設定により利用可否が変わる場合があります。
